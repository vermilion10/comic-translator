Comic Translator

Translates comics into English or Indonesian. Right-click any image and choose “Translate this comic page”.

Source language

Which script the page you are reading is written in. This picks the text recognition model: each script needs its own, and the wrong choice produces nonsense rather than a visible failure. Set it before translating.

Translate into

English works with either translator. Every other language needs Cloud: the on-device model only translates into English.

Translation

Where the recognised text gets translated. On this device is the default and needs no account, no key and no network: a 1.5 GB model downloads once and then runs on your GPU. Cloud exists for devices that cannot run it, which means devices without WebGPU.

Cloud translation sends your text to Google

This is a genuinely different privacy tradeoff from the on-device model, not a faster version of it. With Cloud selected:

  • The text recognised from every page you translate is sent to Google’s Gemini API. The images are not, only the text.
  • On Google’s free API tier, they say that content may be used to improve their products. Paid tiers say it is not.
  • Your API key is stored unencrypted in this browser’s extension storage on this device. It never syncs anywhere.

On-device translation sends nothing at all. If that matters more to you than translating on this particular machine, leave this set to “On this device”.

Get a free key from Google AI Studio. The free tier is rate limited per minute; a whole page is sent as one request so a normal page fits inside it.

Detection confidence

How sure the detector must be before a region is translated. Lower finds more text but picks up more false positives; higher is stricter and may skip faint or unusual lettering. Takes effect on the next translation.
